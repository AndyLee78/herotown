# 후반 콘텐츠 (2026-11-25)

전체 흐름 점검(Docs/balance.md)에서 가장 큰 문제는 마을 Lv7 이후 할 일이 없다는 것이었다. 접속 시간의 약 68%가 "분수 소원 말고 할 일이 없는" 상태였고, 재료는 세 종류가 100개 넘게 쌓였다. 마을을 Lv10까지 넓히고 후반 콘텐츠를 단계별로 붙인다.

## 결정 사항 (2026-11-25)

- 후반에 넣을 것: 마을 Lv8–10, 건물 상위 레벨, 전설 장비 등급, 기념물 건설, 끝없는 던전, 요일 던전, 이벤트 던전, 레이드, 마을 침공 방어.
- **전투 콘텐츠의 보상이 후반 성장을 이끈다(2026-11-25 사용자 결정).** 전투 콘텐츠마다 고유한 후반 자원을 주고, 마을 Lv8–10 승격·상위 건물·전설 장비가 그 자원을 요구한다. Lv10 이후에도 기념물, 전설 장비 강화 확장, 끝없는 던전 기록, 이벤트 상점, 레이드 난이도로 계속 쓴다.

| 콘텐츠 | 얻는 자원 | 성격 |
| --- | --- | --- |
| 요일 던전 | 속성 정수 | 매일 조금씩, 꾸준히 |
| 끝없는 던전 | 심연석 | 깊이 갈수록 많이 |
| 레이드 | 보스 전리품 | 드물고 귀함 |
| 마을 침공 방어 | 용맹 훈장 | 주기적으로 오는 위기의 보상 |
| 이벤트 던전 | 이벤트 증표 | 기간 한정 상점 |

자원이 먼저 있어야 쓰는 곳을 만들 수 있으므로 단계를 다시 나눴다.

| 단계 | 내용 |
| --- | --- |
| 4a | 후반 자원 체계, 요일 던전, 끝없는 던전 |
| 4b | 마을 Lv8–10 승격 조건, 상위 건물 비용, 전설 장비를 새 자원으로 다시 연결 |
| 4c | 레이드, 마을 침공 방어(Lv9·10 승격 조건) |
| 4d | 이벤트 던전, 기념물, Lv10 이후 소모처 |

아래 "마을 Lv8–10·상위 레벨·전설 장비"는 처음 만든 틀(d89e486)이다. 틀(레벨 표, 마을 레벨 제한, 추가 재료 비용, 등급)은 그대로 쓰고, 4b에서 비용과 승격 조건을 새 자원으로 바꾼다.

- 마을 Lv10까지 약 1–2주가 걸리게 한다(Lv8 2–3일, Lv9 약 1주, Lv10 약 2주). 4b–4d가 명성을 더 주므로 그때 다시 맞춘다.

## core (Claude Code)

- `villageRules.levels`에 8–10, 건물 레벨 항목의 `town`(필요한 마을 레벨)과 `bone`·`herb`·`crystal`(선택).
- 건설·제작 비용은 뼈·약초·수정도 확인하고 뺀다. 마을 레벨이 모자라면 notice `locked`.
- `GearGrade`에 `epic`·`legend`. 대장간 레시피는 smithLevel 99(기본 검)만 빼고 모두 만들 수 있다.
- 각 건물의 레벨 표(guild·alchemy·magic·training·inn·market·tavern·school·legends) 끝에 새 레벨 값을 더했다.
