# 클래스와 영웅

원문: GDD 4장. 프로토타입은 고용 전에 능력치를 범위로만 보여주고, 상위 직업·성격·유전은 넣지 않는다.

## 능력치

신체는 힘·민첩·체력, 정신은 지능·의지·지혜다. 보이는 전투 능력치는 잠재력에 나이 배율과 훈련을 더해 만든다. 해가 바뀌면(겨울 다음 봄) 고용한 영웅과 여관 방문자가 `ageUp`으로 한 살 먹고, 능력치는 `withAge`가 나이대로 다시 계산한다. 80세에 닿아도 은퇴하거나 죽지 않는다. 고용 전에는 각 능력치를 대략 ±25% 범위로 보여 주고, 숨은 잠재력은 낮음·중간·높음으로만 보여 준다.

## 특성

강인함, 겁쟁이, 야행성, 보물 사냥꾼, 강철 의지, 허약. 방문자마다 하나다.

## 상태

건강 → 피로 → 부상 → 중상 → 사망. 휴식은 피로를 줄이고, 피로가 0이면 상태를 한 단계 되돌린다. 사망은 휴식만으로 돌아오지 않는다. 부활과 장비 분실은 이 프로토타입에 없다.
