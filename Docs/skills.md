# 스킬과 훈련소 (2026-11-24)

지금까지 영웅은 레벨업마다 스킬 포인트를 받아 스킬을 "배웠다". 그런데 전투는 배운 스킬을 보지 않고 역할(탱커·딜러·힐러·서포터)대로만 움직였다. 이 문서는 배운 스킬이 실제로 효과를 내게 하고, GDD 3.2·12장 2단계의 훈련소를 만든다.

## 결정 사항 (2026-11-24)

- 역할 행동(탱커 도발, 힐러 회복, 서포터 버프·디버프)은 지금처럼 **타고난다**. 배운 스킬은 **새 효과를 더한다**. 그래서 초반 밸런스는 거의 그대로다.
- 직업마다 첫 스킬은 기본기다. 나머지 **세 개 중 두 개만** 배운다. Lv3에 하나, Lv7에 하나다. 같은 직업이라도 영웅마다 구성이 달라진다.
- 훈련소는 **뒤처진 영웅을 끌어올린다**. 스킬을 다시 고르는 곳도 훈련소다. 마을 Lv3에 열린다.

- 기존 세이브에서 세 개를 다 배운 영웅은 먼저 배운 두 개만 남는다. 스킬 포인트는 레벨에서 다시 계산한다.

## 훈련소

- 마을 Lv3에 열린다. 레벨 1–3이다. 레벨만큼 영웅을 동시에 훈련한다.
- **훈련:** 마을에 있는 영웅을 보내면 일정 시간 동안 원정 중처럼 바쁘다. 끝나면 경험치를 받는다.
  - 기준은 로스터에서 레벨이 가장 높은 다섯 명의 평균 레벨이다. 그보다 2 이상 낮으면 한 번에 거의 한 레벨이 오른다. 1 낮으면 반 레벨쯤, 따라잡았으면 조금만 오른다.
  - 비용은 골드(레벨에 비례)다. 시간은 10분이고, 레벨 2·3에서 8분·6분으로 줄어든다.
- **다시 고르기:** 골드를 내고 배운 스킬 하나를 잊는다. 포인트가 돌아오므로 다른 스킬을 배울 수 있다.
- 새로 고용한 영웅과 성인이 된 아이를 빨리 파티에 넣는 용도다.

## 밸런스 (2026-11-24)

스킬 두 개를 배운 파티가 **레벨 하나 더 높은 파티와 비슷하게** 되도록 맞췄다. 그래야 물약·장신구·작전으로 대비하는 재미가 남는다. 시작 파티 40개 × 6전, 중앙값/하위 25%다.

| 권장 레벨에서 | 스킬 없음 | 스킬 없음, 레벨 +1 | 스킬 두 개 |
| --- | --- | --- | --- |
| 독늪 Lv12(물약 없음) | 83% / 0% | 100% / 83% | 100% / 50–100% |
| 도적 요새 Lv14(장신구 없음) | 100% / 33% | 100% / 83% | 100% / 83% |

- 처음 수치(공격 +10–12%, 방어 −12%, 속도 +12%, 약화 30%)로는 독늪 100% / 83–100%, 요새 100% / 100%가 됐다. 대비할 이유가 사라져서 줄였다.
- 처음 "정화"는 중독을 통째로 풀어서, 이것 하나로 독늪이 100% / 100%가 됐다. 그래서 절반만 푼다.
- 지금까지의 승률 곡선(`tools/curve.ts`)과 초반 시뮬레이터는 스킬을 배우지 않은 영웅 기준이다. 실제 플레이에서는 Lv3·Lv7부터 조금 더 쉽다.
