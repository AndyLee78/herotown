# 원정 (전투 준비 → 출정 → 진행 → 귀환)

원문: GDD 7장(던전과 전투), 8장(자동화). 2026-11-23 설계. 참고: 길드 경영 게임의 "던전 → 출발 준비 → 파티원 선택 → 던전 연대기" 흐름과, 메인 화면 아래쪽에 진행 중인 던전을 띄우는 방식.

지금은 출정 버튼을 누르는 순간 전투가 끝나고 보상이 들어온다. 이것을 **시간이 걸리는 원정**으로 바꾼다. 결과는 출정할 때 정해지지만(같은 시드·같은 결과), 플레이어는 영웅들이 마을을 나가 싸우고 돌아오는 과정을 시간에 맞춰 본다.

## 1. 화면 흐름

하단 독의 "편성"을 **전투**로 바꾸고, "결과"는 전투 창의 "원정 기록" 탭으로 옮긴다.

```
[독: 전투] ─▶ ① 던전 탭 ── 출발 준비 ─▶ ② 출발 준비 ── 파티 구성 ─▶ ③ 파티 편성
                │                         │
                └ 원정 기록 탭(④)           └ 출정 ─▶ 마을에서 출발 장면 ─▶ ⑤ 진행 패널
```

### ① 던전 탭
- 왼쪽: 던전 목록. 티어 색 번호, 이름, 권장 레벨, 클리어 표시. 잠긴 던전은 "???".
- 가운데: 선택한 던전 정보. 이름·티어·권장 레벨·층 수, 보스와 일반 몬스터 3D 초상, 공략 힌트 한 줄.
- 오른쪽: 보상. 첫 클리어(명성·골드·재료)와 반복·자동 보상.
- 아래: [출발 준비].
- **잠금 규칙:** 티어 1은 처음부터 열림. 티어 N은 티어 N−1 던전을 하나라도 클리어하면 열림.

### ② 출발 준비
- 파티 프리셋 카드 3개. 카드마다 이름, 영웅 초상 5칸, 전투력 합, 경고(지침·부상·죽음을 본 자), 이미 원정 중이면 "원정 중".
- 카드를 고르면 그 파티의 작전(우선 대상·회복 기준·후퇴 기준)을 보여 주고 바로 고칠 수 있다. 작전은 프리셋마다 따로 저장한다.
- [파티 구성하기]로 ③을 연다.
- **준비물:** 연금술 공방(단계 3) 전까지는 자리만 두고 "연금술 공방이 생기면 쓸 수 있다"고 표시한다.
- [출정](도장 버튼). 경고가 있으면 지금처럼 확인 창.
- 동시 원정 수는 길드 레벨의 "동시 출정"(expeditionSlots)까지. 넘으면 출정 버튼이 막히고 이유를 보여 준다.

### ③ 파티 편성
- 왼쪽: 영웅 목록. 역할 필터(탱·딜·힐·서포트), 정렬(레벨·전투력·피로). 한 줄에 초상·클래스·레벨·전투력·피로 막대·상태. 원정 중인 영웅은 흐리게, 고를 수 없음.
- 오른쪽: 대열판(전열 2·후열 3)과 프리셋 이름. 영웅을 누르면 빈 자리에 들어가고, 자리를 누르면 열 바꾸기/빼기.
- [저장]. 한 영웅은 여러 프리셋에 들어갈 수 있지만 동시에 두 원정에 갈 수는 없다.

### ④ 원정 기록
- 최근 10개(직접 출정만. 자동 출정은 부재 중 보고서로 충분). 카드: 승패, 던전, 파티 초상, 얻은 골드·재료·경험치, 걸린 시간, [다시 보기](3D 전투 재생).

### ⑤ 진행 패널 (메인 화면)
- 원정이 하나라도 진행 중이면 화면 아래(독 위)에 진행 패널이 뜬다. 데스크톱은 가로 띠, 폰은 접을 수 있는 카드.
- 패널 구성: 왼쪽 로그(최근 몇 줄), 가운데 작은 3D 전투 화면, 위쪽 단계 막대(이동 → 1층 → 2층 → 보스 → 귀환), 오른쪽 피해량·회복량 순위.
- 원정이 여러 개면 탭으로 고른다. 접기 버튼이 있다.
- 3D 전투는 **지금 시각에 맞춰** 재생된다. 창을 닫았다 열어도, 새로고침해도 같은 장면부터 이어진다.

## 2. 마을에서 보이는 모습

- **출발:** 출정하면 파티 영웅들이 광장 중앙에 모였다가(준비물을 챙기는 짧은 동작) 줄지어 마을 출구로 걸어 나가 사라진다.
- **원정 중:** 그 영웅들은 마을에 보이지 않는다. 마을 출구 옆 표지판에 원정 중인 파티 수를 띄운다.
- **귀환:** 귀환 시각이 되면 출구에서 걸어 들어와 광장으로 흩어진다. 다친 영웅은 느리게 걷는다(이미 있는 규칙).
- **마을 출구:** 지금 광장 남쪽(+z) 길 끝에 아치형 마을 문을 세운다(Cursor 그림 작업).

## 3. 시간표

출정할 때 core가 전투를 계산하고 시각을 정한다. 숫자는 `src/data/expedition.json`에 두고 조절한다.

| 구간 | 길이 (초깃값) |
| --- | --- |
| 출발 이동 | 20초 |
| 전투 | 전투 틱 × 0.45초 (동굴 약 20초, 광산 약 70초) |
| 귀환 이동 | 20초 |

- **보상과 상태 변화는 귀환 시각에 들어온다.** 결과를 미리 알 수 없게 하기 위해서다. 오프라인이어도 catchUp에서 귀환을 처리한다.
- 원정 중인 영웅은 다른 원정·자동 출정·해고에서 빠진다.
- 자동 출정은 지금처럼 화면 없이 계산한다(GDD 8.1). 원정 중인 영웅은 자동 출정에도 쓰지 않는다.
- 부재 중 보고서에 "돌아온 원정"을 추가한다.

## 4. core 변경

- `GameState.party`, `tactics` → `presets: PartyPreset[]`(3개, id·이름·slots·tactics) + `selectedPresetId`. 예전 세이브의 party·tactics는 첫 프리셋으로 옮긴다.
- `GameState.report` → `history: DungeonReport[]`(최신이 앞, 10개). 리포트에 `finishedAt`, `presetId`, 얻은 재료를 남긴다.
- `GameState.expeditions: Expedition[]` — id, presetId, dungeonId, heroIds, seed, report, departAt, battleAt, battleEndAt, returnAt.
- `depart` 액션은 `{ presetId, confirm?, now }`. 즉시 정산하지 않고 expedition을 만든다. catchUp이 `returnAt`을 지난 원정을 정산한다(settleParty + grantVictoryRewards는 지금 코드를 그대로 쓴다).
- `heroPower(hero)`: 전투 유닛의 공격·방어·체력·속도를 합친 비교용 숫자(피로·부상 반영). 승패 계산에는 쓰지 않는다.
- `dungeonUnlocked(state, id)`: 잠금 규칙.
- `SAVE_VERSION` 올림 + 이전 세이브 변환. 길잡이 3·7단계(동굴·광산 클리어)는 귀환 후에 완료된다.

## 5. 작업 단계와 분담

| 단계 | 내용 | 담당 |
| --- | --- | --- |
| A ✅ | core: 프리셋, 시간 걸리는 원정, 귀환 정산, 기록 10개, 전투력, 잠금, 세이브 변환, 테스트 | Claude Code |
| B ✅ | 전투 창 ①–④ 화면 흐름 | Claude Code |
| C ✅ | 진행 패널 ⑤: BattleScene을 시각에 맞춰 재생(seek), 단계 막대, 로그, 피해·회복 순위 | Claude Code |
| D ✅ | 마을 출발·귀환 동작(VillageScene에서 모이기 → 출구로 걷기 → 사라짐, 귀환은 반대) | Claude Code |
| E ✅ | 그림: 몬스터 3D 초상, 던전별 3D 미리보기 그림, 마을 문(아치), 출정 도장 연출 | Cursor (작업 13) |
| F ✅ | 효과음 연결: 출발 나팔, 귀환, 진행 패널 전투음 | Cursor (작업 13) |

- A는 core만 바꾸지만 `party`·`report` 필드를 없애므로 화면 코드가 함께 바뀐다. **Cursor 작업 10(효과음)이 커밋된 뒤에 시작한다.** 작업 11(나이 먹기)도 game.ts를 건드리므로 A가 끝난 뒤에 넘긴다.
- C의 3D 패널은 BattleScene에 "시각 t에 해당하는 장면으로 건너뛰기"(seek)를 추가해 만든다. 지금의 skip(끝으로 건너뛰기)을 일반화한다.
