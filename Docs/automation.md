# 자동화 확장 (2026-11-24)

GDD 8.3: "대장간·연금술의 자동 제작 대기열도 열린다. 후반에는 마을 운영 자체가 대부분 자동이 되고, 플레이어는 고난도 던전과 세대 관리에 집중한다."

## 문제

대장간, 연금술 공방, 마법 공방은 한 번에 하나씩만 만든다. 끝날 때마다 플레이어가 다음 작업을 걸어야 한다. 다친 영웅은 신전에 직접 보내야 하고, 훈련소도 매번 직접 보내야 한다. 후반에는 건물이 늘어 손이 많이 간다.

## 결정 사항 (2026-11-24)

- 네 가지를 자동화한다. **제작 대기열, 물약 재고 유지, 신전 자동 치료, 훈련소 자동 훈련**이다.
- 대기열에 거는 작업은 **걸 때 비용을 낸다.** 취소하면 돌려받는다.
- 이번 작업은 Cursor 없이 Claude Code와 GPT가 나눠 한다.

## 제작 대기열

- 대장간(제작만), 연금술 공방, 마법 공방이 대상이다. 작업 중일 때 새 작업을 걸면 대기열에 들어간다. 대기열 칸은 **건물 레벨만큼**이다(Lv1 1칸, Lv2 2칸, Lv3 3칸).
- 앞 작업이 끝나는 순간 다음 작업이 시작된다. 자리를 비운 사이에도 차례대로 돈다.
- 대장간 강화는 장비를 맡겨야 해서 대기열에 넣지 않는다(지금처럼 비어 있을 때만).
- 대기열의 작업은 취소할 수 있고, 낸 비용을 그대로 돌려받는다.

## 물약 재고 유지

- 물약마다 "창고에 n개 유지"를 정할 수 있다(0이면 끔).
- 연금술 공방이 비어 있고 대기열도 비어 있으면, 유지 수량보다 적은 물약을 골라 만든다. 재료와 골드가 있어야 하고, 공방 레벨로 열린 물약이어야 한다. 순서는 회복 → 해독 → 각성 → 맑은 정신이다.
- 비용은 시작할 때 낸다(대기열이 아니라 그때그때 만드는 것이다).

## 신전 자동 치료

- 켜 두면(기본값 켬) 다친 영웅(부상·중상)이 마을에 있을 때 신전이 알아서 치료를 시작한다. 치료는 무료라서 손해가 없다.
- 부활은 골드가 들어서 자동으로 하지 않는다.

## 훈련소 자동 훈련

- 켜 두면(기본값 끔, 골드가 든다) 훈련소 자리가 빌 때마다 파티보다 1레벨 이상 뒤처진 마을 영웅을 가장 뒤처진 순서로 보낸다. 다친 영웅, 원정·정찰 중인 영웅, 아이는 보내지 않는다. 골드가 모자라면 보내지 않는다.
- 선택한 파티와, 자동 출정이 실제로 쓰는 파티(길드 Lv3의 두 번째 파티, 고정 정책의 파티)의 영웅은 보내지 않는다.
- 원정이나 정찰에서 돌아온 영웅은 다음 정산부터 훈련 대상이 된다.

숫자는 `src/data/automation.json`에 있다.

## 리뷰 반영 (a6be730, 2026-11-24)

- 건설이 끝나는 순간에서 시간 처리를 한 번 끊는다. 그래서 그 전의 공방 작업은 예전 레벨로, 그 뒤의 작업은 새 레벨로 진행한다.
- 자동 치료는 마을에 있던 부상자는 정산이 시작될 때, 원정에서 돌아온 부상자는 돌아온 시각에 시작한다. 같은 정산 안에서 치료가 끝나면 바로 낫는다.
- 자동 훈련은 자동 출정이 실제로 쓰는 파티를 비켜 간다. 정찰이나 원정 중인 영웅은 돌아온 뒤에 훈련을 시작한다.
- 물약 유지는 창고 재고 기준이다. 한 번에 2개씩 만들어 목표보다 1개 많을 수 있다. 원정에서 쓰지 않은 물약이 돌아오면 더 많아질 수 있다.
- 화면(GPT 4bbfcda)은 Claude Code가 개발 화면에서 직접 확인했다. 연금술 공방 창의 "대기열 1/2"와 취소(비용이 그대로 돌아옴), "대기열에 넣기" 버튼, 물약 유지 수량 +/−, 신전 자동 치료 스위치, 훈련소 자동 훈련 스위치와 안내를 확인했다. 개발 중 코드를 바꿔 끼울 때 자동화 정보가 없는 상태가 들어와 멈출 수 있어 방어 코드를 넣었다.
