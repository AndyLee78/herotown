# 감정·사기·축제 (2026-11-24)

GDD 6.6을 실제 규칙으로 옮긴다. 세대 시스템(결혼·출산·죽음)에 감정의 무게를 실어, 영웅과 가문에 대한 애착을 키운다(GDD 12장 2단계의 기준).

## 결정 사항 (2026-11-24)

- 사기를 움직이는 감정은 **슬픔, 기쁨, 자부심**이다. 불안과 서운함은 넣지 않는다.
- 축제는 **계절마다 한 번** 열 수 있고, **계절마다 효과가 다르다**.
- 사기는 전투에 **크게** 영향을 준다. 사기가 낮은 영웅은 많이 약해지고 자동 출정에서 빠진다.
- 이번 작업은 Cursor 없이 Claude Code와 GPT가 나눠 한다.

## 사기

- 영웅마다 사기(0–100)가 있다. 기본값은 60이다. 시간이 지나면 시간당 2.5씩 60으로 돌아간다. 그래서 크게 떨어져도 하루(한 계절) 안에 회복된다.

| 사기 | 효과 |
| --- | --- |
| 80 이상 | 공격 +5% |
| 31–79 | 없음 |
| 30 이하 (애도·실의) | 공격·속도 −20%, 자동 출정에서 빠진다 |

## 감정

| 감정 | 계기 | 사기 |
| --- | --- | --- |
| 슬픔 | 배우자가 영원히 떠남(전사·노환) | −50 |
| | 부모나 자녀가 영원히 떠남 | −40 |
| | 친한 동료(호감 40 이상)가 영원히 떠남 | −25 |
| 기쁨 | 결혼 | 둘 다 +25 |
| | 출산 | 부모 +30 |
| | 자녀의 성인식 | 부모 +20 |
| | 마을의 던전 첫 클리어 | 그 파티 +15 |
| 자부심 | 원정 승리(보스 처치) | 그 파티 +3 (승리로는 75까지만 오른다) |
| | 마을 레벨업 | 모두 +10 |

- 승리는 자주 일어나므로, 승리만으로는 사기가 75를 넘지 않는다. 사기 80 이상(공격 +5%)은 축제·결혼·출산·첫 클리어 같은 특별한 일로만 닿는다.
- 첫 사망(신전에서 부활할 수 있음)은 슬픔을 일으키지 않는다. 영원한 이별(두 번째 죽음, 노환)만 슬픔이다.

## 축제

- 마을 광장에서 연다(새 건물 없음). 계절마다 한 번이다. 비용은 골드 50 + 마을 레벨 × 25다.
- 열면 모든 영웅의 사기가 +20 오르고 명성이 +5 오른다. 그리고 계절별 효과가 붙는다.

| 계절 | 축제 | 더해지는 효과 |
| --- | --- | --- |
| 봄 | 파종제 | 그 계절이 끝날 때까지 원정에서 쌓이는 호감도 2배 → 연애·결혼이 빨라진다 |
| 여름 | 무술 대회 | 어른 영웅 모두 경험치(현재 레벨의 30%) |
| 가을 | 수확제 | 나무 30, 돌 30, 철 12 |
| 겨울 | 추모제 | 사기가 기본값(60)보다 낮은 영웅은 +30 더 오른다(슬픔을 빨리 덜어 준다) |

숫자는 `src/data/morale.json`에 있다.
