# 감정·사기·축제 (2026-11-24)

GDD 6.6을 실제 규칙으로 옮긴다. 세대 시스템(결혼·출산·죽음)에 감정의 무게를 실어, 영웅과 가문에 대한 애착을 키운다(GDD 12장 2단계의 기준).

## 결정 사항 (2026-11-24)

- 사기를 움직이는 감정은 **슬픔, 기쁨, 자부심**이다. 불안과 서운함은 넣지 않는다.
- 축제는 **계절마다 한 번** 열 수 있고, **계절마다 효과가 다르다**.
- 사기는 전투에 **크게** 영향을 준다. 사기가 낮은 영웅은 많이 약해지고 자동 출정에서 빠진다.
- 이번 작업은 Cursor 없이 Claude Code와 GPT가 나눠 한다.

## 사기

- 영웅마다 사기(0–100)가 있다. 기본값은 60이다. 시간이 지나면 시간당 2.5씩 60으로 돌아간다. 그래서 크게 떨어져도 하루(한 계절) 안에 회복된다.

| 사기 | 효과 |
| --- | --- |
| 85 이상 | 공격 +5% |
| 31–84 | 없음 |
| 30 이하 (애도·실의) | 공격·속도 −20%, 자동 출정에서 빠진다 |

## 감정

| 감정 | 계기 | 사기 |
| --- | --- | --- |
| 슬픔 | 배우자가 영원히 떠남(전사·노환) | −50 |
| | 부모나 자녀가 영원히 떠남 | −40 |
| | 친한 동료(호감 40 이상)가 영원히 떠남 | −25 |
| 기쁨 | 결혼 | 둘 다 +25 |
| | 출산 | 부모 +30 |
| | 자녀의 성인식 | 부모 +20 |
| | 마을의 던전 첫 클리어 | 그 파티 +15 |
| 자부심 | 원정 승리(보스 처치) | 그 파티 +3 (승리로는 80까지만 오른다) |
| | 마을 레벨업 | 모두 +10 |

- 승리는 자주 일어나므로, 승리만으로는 사기가 80을 넘지 않는다. 사기 85 이상(공격 +5%)은 축제·결혼·출산·첫 클리어 같은 특별한 일로만 닿는다.
- 첫 클리어는 승리의 자부심(+3, 80까지)에 기쁨(+15)이 더해진다.
- 마을 레벨업 자부심은 명성이 어디서 오르든(첫 클리어·건설·축제·의뢰) 들어간다.
- 슬픔은 소식이 오는 순간(원정 귀환, 새해의 노환) 바로 들어간다. 한 원정에서 여럿을 잃으면 가장 큰 슬픔 하나만 들어간다.
- **은퇴 영웅은 사기가 없다.** 싸우지 않으므로 감정·축제의 대상이 아니다. 은퇴 영웅의 죽음은 가족과 친구에게 슬픔을 준다.
- 첫 사망(신전에서 부활할 수 있음)은 슬픔을 일으키지 않는다. 영원한 이별(두 번째 죽음, 노환)만 슬픔이다.

## 축제

- 마을 광장에서 연다(새 건물 없음). 계절마다 한 번이다. 비용은 골드 50 + 마을 레벨 × 25다.
- 열면 모든 영웅의 사기가 +20 오르고 명성이 +5 오른다. 그리고 계절별 효과가 붙는다.

| 계절 | 축제 | 더해지는 효과 |
| --- | --- | --- |
| 봄 | 파종제 | 그 계절이 끝날 때까지 원정에서 쌓이는 호감도 2배 → 연애·결혼이 빨라진다 |
| 여름 | 무술 대회 | 어른 영웅 모두 경험치(현재 레벨의 30%) |
| 가을 | 수확제 | 나무 30, 돌 30, 철 12 |
| 겨울 | 추모제 | 사기가 기본값(60)보다 낮은 영웅은 +30 더 오른다(슬픔을 빨리 덜어 준다) |

숫자는 `src/data/morale.json`에 있다.

## 측정과 리뷰 반영 (2026-11-24)

- GPT 측정(727df45, 시드 20개 × 12시간)에서 사기 80 이상이 시간의 약 70%였다. 그래서 공격 +5%가 거의 늘 켜져 있었다. "의욕 넘침" 기준을 85로 올리고, 승리로 오르는 상한도 80으로 맞췄다.
- 축제 비용은 총수입의 0.5% 안팎이고, 축제가 진행 속도를 크게 바꾸지는 않았다.
- 배우자를 잃으면 실의(30 이하)가 약 8시간, 부모·자녀를 잃으면 약 4시간 이어진다. "크게"를 고른 결정에 맞아서 회복 속도(시간당 2.5)는 그대로 둔다.
- 리뷰 b9036a0은 위 규칙 설명대로 고쳤다.
- 화면(GPT 3068fbd)은 Claude Code가 개발 화면에서 직접 확인했다. 영웅 목록의 사기 막대와 "의욕 넘침"·"실의" 칩, 실의 배지, 계절 축제 창(이름·효과·비용)과 열기 버튼을 확인했다. 축제를 열면 골드·명성·사기가 바로 반영되고 버튼이 "이번 계절 축제 완료"로 잠겼다.
