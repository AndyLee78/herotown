## 확인

- 일반 던전 승리에서 기존 클리어 목록을 기준으로 첫 클리어를 판정한 뒤 장비를 준다. 자동 출정은 반복 승리 확률에 절반 배율을 쓴다. 침공·요일·심연·이벤트는 일반 장비 드롭을 받지 않고, 레이드는 보스 체력 정산으로 단계 처치가 확인될 때 고유 장비만 굴린다.
- 일반·고유 장비는 자동 배율과 행운을 곱한다. 레이드 단계는 25/40/60%로 두 후보 중 하나를 고른다. 난수는 마을 시드와 공유 제작 순번을 사용한다. 동일한 상태와 입력은 같으며, 제작·교환·재굴림을 사이에 하면 이후 드롭 결과가 달라진다.
- 등급은 티어 표에서 먼저 굴린다. 희귀는 방어구 레시피가 없어 무기만 나온다. 무기 종류는 영웅 직업과 무관하게 굴리며, 고유 무기는 무종류라 누구나 낄 수 있다.
- 고유 무기·방어구는 바탕 레시피와 등급별 강화 상한을 쓰고, 장신구는 고정 효과만 받는다. 판매는 정의의 가격과 시장 비율·강화 배율로 계산한다. 정상 고유 장신구는 기존 `trinketOf`에서 null이며 고유 효과는 별도로 붙는다.
- 교환은 던전 클리어와 전체 금고 비용을 검사하고 성공 때만 차감한다. 레이드 고유 교환은 전리품·훈장이 필요하다. 최근 목록은 20개로 제한하며 `seenLoot`는 알림 목록만 비운다. 버전 28에 목록이 없어도 버전 29로 빈 배열을 복원한다.
