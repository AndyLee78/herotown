## 확인

- 일반 목록에서 제외되어 해금 사다리·의뢰·둥지와 첫 클리어 명성에 영향을 주지 않는다. 영웅 개인의 클리어 이력에는 남지만 전설의 티어 판정은 일반 목록만 본다. 정상 플레이에서는 특수가 마을 클리어에 들어가지 않아 자동 선택이 되지 않는다. 가져온 마을 클리어에 특수 ID가 있는 경우를 방어하려면 자동 출정 쪽에도 명시적인 제외 조건이 필요하다.
- 요일과 횟수는 출발 시점의 기기 달력으로 판정한다. 취소나 잘못된 출발은 사용하지 않으며, 출발 성공 후 패배·후퇴는 사용한다. 자정을 넘긴 귀환은 도착 요일을 재검사하지 않는다.
- 심연은 절대 층으로 몬스터를 결정하고 5층마다 보스를 순환시킨다. 층별 스케일이 던전 기본 스케일보다 우선한다. 중간 패배에서도 통과층을 순서대로 지급하고, 새로 넘긴 10층 배수마다 명성을 주며, 5층 완주에서만 체크포인트가 바뀐다.
- 세이브 22의 누락 필드는 빈 금고, 사용 기록 없음, 최고·체크포인트 0으로 초기화한다.
