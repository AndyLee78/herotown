# 행운의 분수 코어 리뷰 — 5322f86

## 발견 사항

### 보통 — 증축이 끝난 구간 전체를 새 레벨의 간격과 상한으로 충전한다

- 위치는 `src/core/game.ts:552`, `572`–`573`, `828`–`839`.
- 따라잡기는 분수 증축을 먼저 완료하고, 그 뒤 변경된 레벨로 마지막 충전 시각부터 한꺼번에 계산한다. 공사 중에 지난 시간에도 짧아진 간격과 늘어난 상한이 소급 적용된다. 이미 가득 찬 분수는 공사가 끝나자마자 새 슬롯까지 채울 수 있다.
- 재현은 Lv1의 마지막 소원을 시각 `t`에 쓰고, Lv2 공사 완료를 `t + 50_000`으로 둔 뒤 그때까지 한 번 따라잡는다. Lv1 간격 60초가 지나기 전에 Lv2 간격 50초가 적용돼 소원이 1개 생긴다. 끝나기 직전에 Lv1 상한에서 충전을 한 번 갱신하느냐에 따라 새 슬롯의 충전량도 달라진다.
- 공사 완료 시각까지 기존 레벨로 먼저 충전하고, 완료 이후 구간에 새 레벨을 적용한다. 완료 시 남은 진행을 유지하는 기준을 명시하고, 가득 찬 상태에서는 새 슬롯의 충전을 완료 시각부터 시작한다. 한 번에 따라잡는 경우와 나눠서 따라잡는 경우를 비교하는 테스트를 둔다.

### 보통 — 시계가 뒤로 갔다가 복귀하면 같은 구간에서 골드를 한 번 더 받는다

- 위치는 `src/core/fountain.ts:34`–`41`, `66`–`77`, `src/core/game.ts:527`–`533`.
- 시계가 뒤로 간 상태에서 빈 분수에 소원을 쓰면 `noWish`를 반환하면서도 `chargedAt`을 과거로 옮긴다. 정상 시각으로 복귀하면 게임 시계상 새 시간이 흐르지 않았어도 과거 구간이 다시 소원으로 바뀐다.
- 재현은 시각 `t`에 시작 소원을 쓴 다음 `t - 60_000`에 `wish`를 보내고 다시 `t`에 `wish`를 보낸다. 마지막 요청도 성공해 `made`가 2가 된다. 따라잡기는 과거 요청을 무시하지만 `wish`는 별도로 충전한다.
- 충전 기준 시각이 뒤로 이동하지 않게 하고, 조회와 소원 사용에서 같은 유효 시각 규칙을 사용한다. 12시간 상한으로 게임 시계가 요청 시각에 못 미치는 상황도 같이 테스트한다.

## 확인함

- 레벨별 충전 간격·상한·지급액·대박 확률·배수, 증축 비용, 은퇴자 보너스 +1%p가 설계와 일치한다. 소원은 골드만 지급한다.
