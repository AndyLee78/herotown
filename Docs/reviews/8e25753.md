# 스킬·훈련소 코어 리뷰 — 8e25753

## 발견 사항

### 보통 — 훈련 중인 영웅을 가족 규칙이 마을에 있는 것으로 취급한다

- 위치 `src/core/game.ts:634`–`647`, `1363`–`1373`, `src/core/family.ts:270`–`290`, `482`–`496`, `src/core/drill.ts:56`–`66`.
- 훈련은 원정과 같은 바쁜 상태여서 출정·정찰·은퇴를 막지만, 임신과 노환은 일반 원정과 정찰만 확인한다. 훈련 도중 노환으로 떠나면 영웅은 명단에서 사라지고 훈련 슬롯은 예정 종료까지 차 있다. 계절 경계에서 임신한 경우에도 기존 훈련은 계속 진행되고, 종료 코드는 임신 여부를 검사하지 않고 XP를 준다.
- 재현은 겨울 종료 1초 전 79세 영웅을 훈련 보내고 새해 1초만 진행한다. 80세 무덤이 생성됐지만 `drills`에 해당 ID가 남았다.
- 훈련 중인 영웅도 원정 중과 같은 가족 판정을 받아야 하는지 명시하고, 공통 바쁨 판정을 적용하거나 로스터에서 제거될 때 해당 작업을 즉시 정리한다.

### 보통 — 구버전에서 보존된 스킬을 잊으면 해금 레벨 전에 다른 스킬을 배울 수 있다

- 위치 `src/core/skills.ts:20`–`30`, `src/core/drill.ts:70`–`86`, `src/core/game.ts:1532`–`1546`.
- 구버전에서 먼저 배운 두 개를 유지하는 정책 자체는 문서와 맞는다. 그러나 잊기는 현재 레벨의 해금 슬롯 수와 관계없이 1점을 돌려주고, 배우기는 저장된 포인트만 검사한다. 이미 가진 저레벨 스킬을 보존하는 범위를 넘어 새 스킬을 골라 효과를 바꿀 수 있다.
- 재현은 `warrior.taunt`가 있는 Lv2 전사를 세이브 13에서 불러와 훈련소의 잊기로 도발을 빼고 곧바로 `warrior.guard`를 배우는 것이다. Lv2인데도 방어를 배웠다.
- 잊을 때 남은 학습 슬롯을 레벨과 남은 스킬 개수로 다시 계산한다. 배우기에서도 해금 슬롯을 검사해 저장된 포인트와 판정을 맞춘다.

### 낮음 — 방어가 중독·함정 피해를 줄이지 않고 작은 공격에서는 반올림으로 사라진다

- 위치 `src/core/combat.ts:310`–`317`, `398`–`405`, `666`–`669`.
- 문서의 “받는 피해” 감소와 달리 방어는 `strike`에서만 적용된다. 중독과 함정은 해당 경로를 거치지 않는다. 일반 타격도 먼저 정수로 만든 뒤 다시 반올림하므로 방어 5%에서 9 피해, 보호막 3%에서 16 피해는 그대로다.
- 재현은 일반 타격이 9가 되도록 고정한 뒤 전사의 방어를 켠 경우와 끈 경우를 비교한다. 둘 다 9다. 같은 최대 체력의 영웅으로 함정 피해를 비교하면 방어 유무와 무관하게 같다.
- 직접 타격만 의도했다면 문구에 범위를 명시한다. 비율을 더 정확하게 반영하려면 원본 난수 결과에 방어를 곱한 뒤 한 번만 반올림하고 최저 피해는 유지한다.

## 확인함

- `createHero`는 직업의 첫 스킬을 보장하고 유효한 기존 선택 두 개까지만 순서대로 보존한다. 레벨업 XP는 `gainXp` 한 곳에서 처리하며 Lv3·7에 배울 자리가 열린다. 방문자·아이는 직업 기본기로 시작하고, 노화·불러오기는 기존 학습을 정규화한다. 은퇴·부활은 저장된 학습을 유지한다.
- 파티 공격 +6%, 방어 8% 상한은 출정 시 적용한다. 개인 방어와 파티 방어는 곱으로 합친다. 약화는 살아 있고 약화되지 않은 적을 해당 효과를 배운 영웅이 때릴 때만 코어 RNG를 소비한다.
- 훈련 XP는 성인·생존 로스터의 상위 다섯 명 평균과 등록 시 격차로 정해진다. 격차 2 이상은 현재 레벨에 필요한 XP 한 레벨분이다. 종료는 따라잡기 시각에 따라 한 번 처리되고, 작업 수는 훈련소 레벨까지다.
- 세이브 14는 세이브 13에 훈련소 0과 빈 훈련 목록을 채운다. 부모 커밋과 스킬 효과가 없는 기존 10개 던전의 전체 시드 전투 리포트 60건이 일치했다.
