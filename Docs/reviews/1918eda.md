# 3a 코어 리뷰 — 1918eda

## 발견 사항

### 보통 — 각성 물약은 이미 걸린 마비를 풀 수 없다

- 위치 `src/core/combat.ts:209`–`217`, `319`–`323`.
- 마비를 먼저 해제하고 해당 행동을 건너뛰므로, 물약 판단에 도달할 때에는 마비 상태가 남아 있지 않다. 각성 물약은 둔화에만 반응한다. 설계는 각성 물약으로 마비와 둔화를 모두 해제한다고 설명한다.
- 재현은 `depth.test.ts`의 물약 테스트처럼 단일 영웅에게 `paralyzed = true`, 물약 꾸러미에 `{ tonic: 1 }`을 주고 `simulateFloor`를 실행한다. 처음 행동에서 `log.paralyzed`가 발생하고 각성 물약은 사용되지 않는다.
- 각성 물약이 마비를 해제할 기회를 건너뛰기 판정 앞에 두고, 마신 행동을 소모하는 기존 정책은 유지한다.

### 보통 — 침묵 적이 힐러와 서포터를 우선 표적으로 삼지 않는다

- 위치 `src/core/combat.ts:354`–`371`, `430`–`436`.
- 도깨비불과 늪의 여왕의 단일 공격도 일반 위협도 순서를 공유한다. 전사가 살아 있고 위협도가 가장 높으면 도깨비불은 옆에 힐러와 서포터가 있어도 전사를 공격해 침묵을 건다. 보스 광역 공격은 별도로 전원에게 적용된다.
- 재현은 전사·성직자와 `wisp` 한 마리로 전투를 돌리고 `log.attack`의 표적을 확인한다. 전사의 위협도가 높은 동안에는 성직자 대신 전사가 선택된다.
- 침묵을 가진 적의 단일 공격에서만 살아 있는 힐러·서포터를 우선 후보로 삼고, 후보가 없으면 기존 위협도를 사용한다.

### 보통 — 연금술 공방을 올려도 기존 물약 제작 시간이 줄지 않는다

- 위치 `src/core/alchemy.ts:16`–`20`, `src/data/alchemy.json:7`–`38`.
- 공방 레벨은 제조법 해금에만 쓰인다. 제작 시간은 물약별 고정 시간과 은퇴자 보너스로 정해져, 공방 레벨이 오르면 시간도 준다는 설계와 다르다.
- 재현은 은퇴자가 없는 동일한 마을에서 공방 Lv1과 Lv3의 `brewTime(state, 'antidote')`를 비교한다. 두 값 모두 600,000ms다.
- 공방 레벨별 제작 시간 배율을 데이터로 정의하고, 은퇴자 보너스를 함께 받는 경우까지 테스트한다.

### 낮음 — 해독 면역 카운터가 물약을 마신 행동에서 바로 줄어든다

- 위치 `src/core/combat.ts:313`–`317`, `342`–`351`.
- 해독 직후 카운터는 6이지만 같은 행동의 종료 처리에서 즉시 5가 된다. 설계의 “해독 후 6행동 면역”을 마신 뒤의 행동으로 읽으면 한 행동이 짧다.
- 재현은 중독 수치가 해독 임계값 이상인 영웅에게 해독 물약 한 개를 주고, 처음 물약 행동 직후의 `immunePoison`을 확인한다.
- 새로 얻은 면역은 다음 행동부터 감소시키고, 정확한 면역 경계를 테스트한다.

## 확인함

- 기존 티어 1–3은 부모 커밋과 독립 비교했다. 여섯 던전의 Lv1·4·7·10 중앙값/P25 24칸과, 24개 시드 전투의 승패·틱·클리어 층·상태·로그가 일치했다. 기존 적은 추가 상태 확률이 0이라 해당 RNG를 소비하지 않는다.
- 기존 중독 상한 18과 독늪의 공격자별 40–48을 사용하며 층 사이에 중독을 지운다. 둔화는 게이지를 30% 늦추고, 마비 뒤 연속 마비를 막는다. 패배 사유는 후퇴, 탱커/힐러, 중독/침묵/마비, 레벨/시간 순이다. 회복 물약은 힐러 부재 사유를 대신한다.
- 수동 출정은 보유량과 파티당 6개 상한 안에서 꺼내며 계획은 프리셋에 남는다. 사용분만 빠지고 미사용분은 귀환 시 현재 창고에 더한다. 자동 원정도 선택 프리셋의 물약과 같은 차감·반납 규칙을 사용한다.
- 공방은 마을 Lv4에서 열리고 동시에 한 제조만 진행한다. 약초는 이끼 길의 추가 보상 및 독늪 보상으로 지급한다. 마을 Lv4 기준은 명성 90이며 독늪 입장 조건은 티어 3 전부 클리어다.
- 세이브 11은 구버전에 약초 0, 빈 물약 창고, 미건설 공방을 채운다. 구버전 작전은 회복 물약 임계값의 기본값으로 동작한다. 새 확률은 코어 RNG를 사용한다.
