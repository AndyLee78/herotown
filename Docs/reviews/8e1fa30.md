# 면담·스카우팅 코어 리뷰 — 8e1fa30

## 발견 사항

### 보통 — 유료 면담도 같은 계절의 여관 업그레이드로 열린 무료 몫을 소비한다

- 위치 `src/core/scouting.ts:20`–`27`, `38`–`49`.
- 무료와 유료를 모두 `used`에 더한다. 같은 계절에 여관이 올라 무료 한도가 늘어도, 이전 유료 면담이 새 무료 슬롯을 이미 사용한 것으로 계산된다.
- 재현은 봄에 여관 Lv1에서 한 명을 무료로, 한 명을 10골드로 면담한 뒤 Lv2로 올리는 것이다. 무료 잔여가 0이고 다음 면담도 10골드다.
- 계절당 무료로 처리한 면담 횟수를 별도로 기록한다. 이전 유료 면담까지 새 무료 한도에 포함하는 정책이라면 업그레이드 안내에 명시한다.

### 낮음 — Lv3 여관에서 첫 면담 한 번으로 전성기 능력치까지 공개한다

- 위치 `src/core/scouting.ts:29`–`49`.
- `Docs/scouting.md`는 잠재력·특성을 보고 Lv3에서 “한 번 더” 깊이 알게 된다고 설명한다. 구현은 현재 여관 레벨로 목표 깊이를 정하고 바로 저장하므로 Lv3의 새 방문자는 0에서 2로 이동한다. 이미 깊이 1인 방문자만 깊은 면담을 별도 단계로 거친다.
- 재현은 Lv3 여관의 미면담 방문자를 한 번 면담하는 것이다. 사용량은 1이고 깊이는 2다.
- 별도 면담이 의도라면 한 번에 깊이를 한 단계 올린다. 한 번에 공개하는 현재 동작이 의도라면 문서를 구체화한다.

### 낮음 — 잠재력이 이미 100을 넘는 방문자가 숨은 인재가 되면 잠재력이 내려간다

- 위치 `src/core/hero.ts:59`–`72`, `202`–`216`, `src/core/scouting.ts:60`–`67`.
- 기본 방문자 생성은 마을 보너스와 난수를 더한 잠재력을 그대로 저장한다. 마을 Lv7에서는 잠재력 100을 넘는 방문자를 만들 수 있다. 숨은 인재 분기가 이 값을 100으로 줄이면 기존 잠재력과 개별 잠재 능력치의 배율도 낮아진다.
- 재현은 잠재력 110인 방문자를 숨은 인재 분기에 보내는 것이다. 결과 잠재력은 100이며, 원본 능력치가 충분히 크면 배율 적용과 반올림 후 수치가 감소한다.
- 100이 전역 상한이면 기본 생성에서도 같은 상한을 적용하고 개별 능력치를 일관되게 계산한다. 일반 방문자의 기존 범위를 유지한다면 숨은 인재 보정으로 기존 잠재력이 감소하지 않게 한다.

### 낮음 — v1 세이브의 기존 방문자는 면담 전 상태로 바뀐다

- 위치 `src/core/game.ts:1911`–`1917`, `1934`–`1938`, `2339`–`2343`.
- v2~17의 기존 방문자는 깊이 1로 이관된다. v1은 정규화에 넘기기 전에 버전을 18로 바꿔 기존 방문자 이관 조건을 건너뛴다.
- 재현은 정상 방문자·로스터가 들어 있는 v1 상태를 `migrate`에 넘기는 것이다. 같은 방문자를 v17로 넘기면 깊이 1, v1에서는 깊이 0이다.
- 원본 버전을 기준으로 방문자 정보 이관을 마친 다음 최종 버전을 기록한다.

## 확인

- 연도·계절 키가 바뀌면 무료 횟수가 복구된다. 무료 소진 후에는 10골드이고, 골드 부족이나 이미 끝낸 면담은 횟수를 쓰지 않는다.
- 일반 도착은 기존 방문자 생성 시드와 호출을 그대로 사용하고, 숨은 인재와 조건만 별도 시드에서 처리한다. 숨은 인재의 현재 수치는 변경한 나이와 잠재 능력치로 다시 계산되고 전성기 표시는 27세 수치다.
- 최초 방문자에는 숨은 인재·고용 조건이 없다. 이후 방문자는 잠재력 70/85 이상에서 마을 Lv3/4가 필요하며, 면담 여부와 관계없이 고용 시 조건을 검사한다. 거절 응답은 `hireTown`만 반환해 설계 문서의 정확한 요구 레벨을 안내하려면 응답에 레벨도 실어야 한다.
- 나이 변경과 세이브 정규화에서 면담 깊이·숨은 인재·조건이 유지된다. 체류 시간이 끝난 방문자는 제거되고 새 방문자의 면담 깊이는 초기 상태다. 고용은 방문자 객체를 로스터로 옮겨 해당 필드를 보존하고, 조건 검사는 고용 시에만 쓴다.
- 디버그 방문자 새로고침은 실제 도착 경로를 거치지 않아 숨은 인재·고용 조건 테스트에는 일반 도착이나 테스트 세이브가 필요하다.
