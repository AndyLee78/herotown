# 5a 코어 리뷰 — 318455b

### 보통 — 수호천사가 여러 명이면 원정에서 여러 번 전멸을 되돌린다

- 위치 `src/core/combat.ts:460`–`473`.
- 소모 여부를 파티가 아니라 발동한 영웅마다 기록한다. 파티는 전멸할 때마다 아직 쓰지 않은 다음 수호천사를 고른다.
- 수호천사를 가진 Lv1 전사 두 명을 고룡과 드레이크 배율 8에 보내 시드 1에서 부활 로그를 두 번 확인했다.
- 설계의 원정당 한 번을 파티 공용 상태로 관리하고, 층 사이에도 유지한다.

### 보통 — 방어 프리셋에서 친한 동료 조건이 발동하지 않는다

- 위치 `src/core/invasion.ts:39`–`88`, `src/core/game.ts:1314`–`1323`, `src/core/combat.ts:249`.
- 일반·자동 원정은 파티원에 유대 정보를 달지만 침공은 영웅과 위치만 넘긴다. 직업 동행 조건은 `runDungeon`이 다시 구성하므로 동작하고, 유대의 정보만 빠진다.
- 친구인 음유시인과 동료를 같은 방어 프리셋에 넣어도 찬가의 추가 파티 공격 1%가 계산되지 않는다.
- 공통 파티 조립 경로에서 유대 조건을 구성하고 침공에도 사용한다.

### 보통 — 저장의 기술 선택 수가 영웅 레벨을 초과할 수 있다

- 위치 `src/core/skills.ts:53`–`67`.
- 순서와 최대 여섯 선택만 검사한다. Lv1 전사에게 유효한 두 갈래를 넣어 저장을 이관하면 두 숙련을 그대로 얻는다. 남은 포인트를 0으로 제한하는 것으로는 장착 스킬 효과를 막지 못한다.
- 정상 예전 세이브의 스킬을 보존하는 예외를 명시하고, 나머지 저장에는 레벨별 선택 상한을 적용한다.

### 낮음 — 관통은 장갑의 피해 감소를 우회하지 못한다

- 위치 `src/core/combat.ts:937`–`945`.
- 장갑 감소 분기는 치명 여부만 보고, 관통은 일반 방어 수치에 따로 적용된다. 관통이 높은 경우에도 장갑의 피해 감소 자체는 유지되어 설계 표의 대응 수단과 차이가 있다.
- 관통이 장갑 감소에도 영향을 주는지 규칙을 확정하고 설명 또는 공식을 맞춘다.

### 낮음 — 행운아 재료 보상 및 정산 효과의 파티 조건이 빠진다

- 위치 `src/core/dungeon.ts:88`–`107`, `src/core/game.ts:1439`–`1461`.
- 행운아는 승리의 기본 골드에 최대 한 영웅의 보너스만 적용한다. 재료 지급에는 연결되지 않았다. 골드·피로의 스킬 집계는 전투와 달리 직업·유대 조건 없이 호출한다. 현재 해당 보상을 올리는 조건부 데이터는 없으나 추가하면 전투와 정산의 효과가 달라진다.
- 자료와 구현에서 재료 보상 적용 여부를 통일하고, 출발 시 평가한 조건을 전투와 정산이 공유하게 한다.

## 확인

- 배우기는 포인트와 앞 단계, 잊기는 뒤 단계 유무를 검사한다. 읽을 때 기본기를 복구하고 먼저 나온 유효 선행 스킬을 기준으로 뒤 단계를 유지한다. 갈래 숙련 활성과 성격 배율은 습득한 기술과 숙련 효과의 합산에서 적용한다.
- 성격·사기·직업·유대 조건은 출발 상태에서, 결사의 낮은 체력은 피해 계산에서 평가한다. 일반 원정, 자동, 레이드, 심연에 공통 던전 진입점이 쓰인다. 훈련은 전투 효과를 굴리지 않으며 경험치 지급은 늦깎이의 Lv15 기준을 따른다.
- 방문자·자녀의 천부는 별도 시드로 굴린다. 신동 보정과 영웅의 핏줄 보정은 생성 경로에 있고, 저장 이관과 레벨업에서는 기존 잠재력을 읽으므로 다시 더하지 않는다. 버전 26의 빈 천부는 비워 둔다.
- 회피 → 치명·장갑 → 일반 방어와 관통 → 보호막 → 불굴 순으로 정산한다. 다음 틱에서 생존한 치유자의 부활, 전멸이면 수호천사를 검사한다. 보스 기절·감속 확률 감소, 기절 뒤 한 차례 내성, 주기적인 약화·감속 해제가 들어간다.
- 회피·치명·상태 효과가 있는 전투와 정예 대상 던전에서는 RNG 소비 순서가 바뀐다. 정예 굴림은 파티가 만나는 처음 배치 몬스터에 있으며, 보스가 나중에 소환한 몬스터는 다시 굴리지 않는다.
- 전투 시작 시 파티 기술 합을 각 상한으로 제한하고, 적 빗나감은 파티원 회피로 합산한 뒤 회피 상한을 적용한다. 원정 피로는 파티 상한과 개인 감소를 별도로 적용한다.
