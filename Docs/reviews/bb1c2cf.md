## 확인

- 시세는 마지막 거래의 `pressureAt`과 정산된 `lastTickAt` 사이의 시간을 사용한다. 1시간 후 75%가 남고, 다른 재료를 거래해도 이미 경과한 만큼만 먼저 감쇠한다. 같은 계절의 특가 두 품목은 서로 다르다.

- 창고만 장비 판매 대상으로 삼고 기본 장비는 판매가가 0이다. 장신구는 제작 골드와 수정을 가격으로 환산한다. 시장 은퇴자 보너스는 재료 매입에 적용되며, 장비·물약 판매가는 각 수식으로 계산된다.
