## 확인함

- 가족 시스템은 코어에 있고 UI·DOM을 가져오지 않는다. 결혼·출산·유전 추첨은 코어 RNG와 시드·nonce를 사용하며 주요 밸런스 값은 family.json에서 읽는다. 기존 외형의 ID 기반 추첨은 이전 look.ts와 호출 순서가 같다. look.test.ts에 기존 두 외형과 저장 유전자 테스트가 있다.
- 세이브 8로 올렸고 이전 세이브는 가족 목록과 nonce를 기본값으로 읽는다. 일반 경로에서 청혼 생성 시 양쪽 영웅을 즉시 점유 처리하므로 같은 영웅이 두 청혼에 들어가지 않는다. 빈 신혼집이 없으면 승인할 수 없다.
- 양쪽 배우자의 원정 여부를 임신 판정에 사용하고 임신하면 `canDeploy`가 거짓이 된다. 청혼은 원정 중에도 가능하며 설계의 청혼 조건에는 원정 제한이 없다. 기존 배우자·호감도는 은퇴 후에도 유지되고, 해고·묘지 이동 때는 남은 배우자에게 사별 시각을 기록한다.
- 딸은 무희를 물려받을 수 있다. 아들은 무희 대신 아버지 직업을 사용하며 아버지도 무희인 입력에는 음유시인으로 대체한다.
