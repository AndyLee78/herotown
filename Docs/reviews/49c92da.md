## 확인

- 성격과 유전은 ID 기반 별도 난수에서 정한다. 일반 방문자와 아이 생성의 기존 난수 소비 순서는 유지된다. 전투에 새 난수 호출은 없지만 스탯과 결과가 달라지면 전투 내 분기와 난수 사용 시점은 달라질 수 있다. 유전 분기에 들어갈 확률은 70%이며 나머지 30%의 새 추첨에서도 우연히 부모와 같은 성격이 나올 수 있다.
- 이전 세이브의 활동 영웅·방문자·아이·은퇴자는 영웅 정규화에서 성격을 받는다. 일반 승리의 사기 상한은 성격 배수를 적용한 후 자르므로 야망가도 자부심만으로 75를 넘지 않는다. 결혼·출산·성인식·첫 클리어·슬픔·마을 레벨업은 각 감정 배수를 읽는다.
- 파티 합산 보정은 −6%~+5%로 잘리고 자동 출정까지 전달된다. −6%는 양의 공격력 배율 0.94이며 피해 하한은 기존 계산 경로를 유지한다.
- 자동·수동 모두 귀환 시 패배로 연패를 늘리고 승리로 초기화한다. 후퇴도 패배로 집계하며 첫 전사자의 사기는 사망 상태에서 움직이지 않는다. 영구 사망자는 없어지고 중상으로 돌아온 사람의 가족에게 불안이 적용된다.
- 서운함은 직접 출정 시 이미 바쁜 영웅을 제외하고 호감도 친구 기준으로 센다. 발동하거나 본인이 자동·수동 원정에서 귀환하면 초기화된다.
