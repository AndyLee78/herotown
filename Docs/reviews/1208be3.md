# 길드 코어 리뷰 — 1208be3

## 발견 사항

### 높음 — 시즌 경계를 넘긴 자동 출정이 이전 계절 의뢰를 처리한다

- 위치 `src/core/game.ts:635`, `652`–`671`, `1140`–`1166`.
- 일반 원정은 각 구간에서 정산하지만 게시판 갱신은 모든 자동 출정 이후에 한 번만 한다. 시간이 새 계절로 넘어간 뒤에도 자동 승리가 이전 계절 의뢰의 골드·명성·실적을 지급할 수 있고, 새 계절 의뢰에는 진행이 남지 않는다. 여러 계절을 건너뛰면 중간 게시판도 생성되지 않는다.
- 재현은 봄 마지막 1분에 완료까지 동굴 1승이 남은 의뢰와 동굴을 도는 건강한 자동 파티를 준비하고, 자동 출정 1회분 이상의 시간을 넘기는 것이다. 여름 게시판이 뜨기 직전의 이전 의뢰 정산 여부를 실적과 골드로 확인한다.
- 계절 구간마다 해당 게시판에서 자동 진행을 처리하고, 경계에서 게시판을 교체한다. 구간 정산에서 소수 시간도 보존하면 짧게 나뉜 경계에서 출정 시간이 소실되는 문제를 피할 수 있다.

### 보통 — 비어 있는 의뢰판이 첫 승리 뒤에도 계절 의뢰를 생성하지 않는다

- 위치 `src/core/guild.ts:63`–`65`, `92`–`112`, `134`–`150`.
- 클리어한 던전이 없는 상태에서 길드를 지으면 빈 계절 의뢰 목록에도 계절 키를 기록한다. 첫 승리에서는 빈 목록을 모두 완료한 것으로 처리해 반복 의뢰를 만들고, 같은 계절의 게시판 갱신은 이후에도 생략된다.
- 재현은 클리어 기록 없이 길드 Lv1에서 게시판을 만든 다음 같은 계절에 동굴을 처음 클리어하는 것이다. 계절 의뢰 2개 대신 반복 의뢰 하나만 남는다.
- 유효한 후보가 생겼을 때 처음 한 번 게시판을 생성한다. 이미 생성된 게시판은 계절 중 업그레이드로 Lv1→2 또는 Lv3→4가 되어도 기존 2개 또는 3개를 유지한다. 의뢰 개수가 생성 시 레벨 기준이라는 정책을 문서와 화면에 명시한다.

### 보통 — 자동 출정 두 번째 파티를 고를 때 뒤쪽의 유효한 프리셋을 건너뛴다

- 위치 `src/core/game.ts:1045`–`1069`, `1085`–`1097`.
- 첫 두 프리셋을 자른 뒤 중복 영웅을 제거한다. 두 번째가 비었거나 전원이 겹치면 세 번째에 완전한 파티가 있어도 첫 번째만 출정한다. 일부만 겹치면 프리셋의 일부 영웅만 출정한다.
- 재현은 길드 Lv3에서 p1과 p2를 같은 영웅으로 편성하고, p3에는 별개 영웅을 넣어 동굴 자동 출정을 1시간 정산하는 것이다. p3에는 자동 전투 정산이 없다.
- 선택한 프리셋부터 순회하면서 유효하고 겹치지 않는 파티를 확보할 때마다 정원을 하나 사용한다. 현재 프리셋별 전술·물약 및 미사용 물약 반환 경로는 유지한다.

### 보통 — 짧은 시간 갱신 사이에 자동 출정 시간이 누락되고, 배치마다 전투 시드가 반복된다

- 위치 `src/core/game.ts:420`–`427`, `668`–`669`, `1079`–`1103`, `1111`–`1118`.
- 호출마다 경과 시간과 출정 횟수를 새로 만든다. 같은 20분을 1분씩 갱신하면 자동 출정이 없고 한 번에 갱신하면 출정한다. 휴식으로 `day`를 올리지 않는 한 여러 번의 20분 정산이 같은 시드로 시작한다. 파티 상태가 동일하면 같은 전투 난수열을 재사용한다.
- 재현은 길드 Lv1, 자동 출정 켬, 동굴 1회 클리어, 파티 편성을 갖춘 동일한 상태에서 20분 단일 정산과 1분 정산 20회를 비교하는 것이다. 이어 휴식 없이 두 번 20분 정산해 각 호출 첫 전투의 시드 식을 비교한다.
- 자동 출정이 오프라인 전용이라면 해당 시간의 정의를 문서화한다. 시간 분할에 무관한 동작이 목표라면 잔여 시간과 출정 순번을 저장해 사용한다.

### 보통 — 세이브 14의 길잡이 단계가 순서 변경을 따라가지 않는다

- 위치 `src/data/guide.json:47`–`69`, `src/core/game.ts:1852`, `1869`–`1880`.
- 14에서 자동 출정 보상을 받고 길드 단계에 도달한 `guideStep: 6`은 15에서 길드 보상을 건너뛰고 자동 출정 단계로 들어간다. 기존 `auto.enabled`도 보존하므로 조건이 이미 충족되어 같은 골드 보상을 다시 받을 수 있다.
- 재현은 `version: 14`, `guideStep: 6`, `auto.enabled: true`, 길드 Lv0으로 불러와 길잡이를 확인하고 보상을 받는 것이다. 자동 전투 자체는 길드가 생길 때까지 정상적으로 막힌다.
- 14→15에서 자동 출정 보상 수령 이력을 보존하고, 기존 길드 단계 미수령자는 길드 보상을 먼저 받도록 옮긴다.

## 확인

- 레벨별 정원·자동 파티 수·감정 오차·실적 기준과 의뢰 보상 배율은 `Docs/guild.md`와 일치한다.
- 동일 시드·계절 및 동일한 클리어 상태에서 계절 의뢰 생성은 결정적이다. 납품 후보는 클리어 목록 순서에 따라 정렬되며, 던전의 주 재료만 포함해 부가 드롭은 그 재료가 주 재료인 던전을 열기 전까지 후보에서 빠진다.
- 직접 원정과 자동 출정이 승리 시 공통 보상 경로로 토벌 의뢰를 진행한다. 패배는 토벌 진행을 바꾸지 않는다. 마지막 계절 의뢰와 반복 의뢰는 완료 즉시 반복 의뢰로 교체된다.
- 14 세이브에 길드 게시판 필드가 없어도 로드하며, 옛 동굴 의뢰 실적을 새 길드 실적으로 전환하는 규칙은 문서에 없다.
