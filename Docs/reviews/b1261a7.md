## 발견 사항

### 보통 — 자동 출정 시간 동안 피로가 두 번 회복된다

- 위치 `src/core/game.ts:735`, `1184`–`1225`, `1345`–`1375`.
- 전체 경과 시간으로 로스터를 먼저 회복시킨 뒤, 성공적으로 구성한 자동 출정 사이클마다 같은 시간만큼 로스터 전체를 다시 회복시킨다. 장기 부재의 시작 파티는 부재가 끝난 시점의 피로를 쓰고, 자동 파티에 속하지 않은 영웅도 추가 회복을 받는다. 집 레벨과 담당 은퇴자 보너스도 두 계산에 들어간다.
- 재현은 피로 95인 비출정 영웅과 동굴을 도는 자동 파티를 두고 출정 한 번의 시간만 정산하는 것이다. 자동 출정을 켠 경우 비출정 영웅의 피로도 끈 경우보다 `회복률 × 출정 시간`만큼 더 줄었다.
- 같은 경과 시간을 한 번만 배분한다. 각 사이클을 해당 시각의 피로로 판정하고, 파티가 비어서 출정하지 못한 사이클도 시간 회복을 진행시킨다.

### 보통 — 실제 자동 출정과 소속 칩이 어긋난다

- 위치 `src/core/readiness.ts:39`–`45`, `src/core/game.ts:1148`–`1150`, `1184`–`1215`.
- 소속은 저장된 고정 자동 파티만 보고, 자동 정책이나 현재 선택 프리셋을 확인하지 않는다. 안전·재료 정책에서 저장만 된 고정 파티에는 자동 소속이 붙고, 지금 자동 출정에 쓰이는 프리셋에는 붙지 않는다. 여러 자동 파티를 쓰는 길드에서 추가 프리셋도 자동 소속에 반영되지 않는다.
- 재현은 안전 정책으로 고른 파티의 A와 예전에 저장한 고정 파티의 B를 나누는 것이다. A는 동굴 자동 출정에 참여하지만 `partiesOf`의 자동 소속은 B에만 붙는다.
- 현재 정책과 프리셋을 바탕으로 후보를 구한다. 칩이 실제 후보인지 저장된 편성인지 의미를 명확히 한다.
