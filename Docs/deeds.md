# 원정에서 생기는 후천적 특성 (2026-11-28)

같은 직업 영웅도 겪은 일에 따라 달라지게 한다. 원정에서 쌓인 기록(**행적**)이 기준을 넘으면 **칭호**가 붙고, 칭호마다 작은 효과가 있다. 타고나는 특성(`traitIds`, 천부 `gift`)과는 따로 둔다.

## 규칙

- 행적은 영웅마다 센다(`Hero.deeds`). 원정 정산 때 그 원정의 보고서(전투 기록·유닛 결과)에서 더한다. 자동 출정도 센다.
- 칭호는 **영웅마다 최대 3개**. 3개가 차면 더 붙지 않는다(먼저 얻은 것이 남는다). 이미 가진 칭호는 다시 붙지 않는다.
- 칭호는 유전되지 않는다. 은퇴·사망해도 기록에 남는다(명예의 전당·묘지에 보인다).
- 효과는 스킬 효과와 같은 합계에 더한다(`heroSkillEffects`). 크기는 천부보다 작게(5d 측정의 천부 효과의 절반 안팎).
- 같은 원정에서 여러 칭호를 얻을 수 있다(3개 한도 안에서, 정해진 순서로).

## 행적(센다)

| 키 | 세는 것 |
| --- | --- |
| `wins` | 이긴 원정 |
| `losses` | 진 원정에서 살아 돌아옴 |
| `bossKills` | 보스를 쓰러뜨린 원정(그 영웅이 그 전투에 있었음) |
| `dragonKills` | 종류가 dragon인 보스를 쓰러뜨림 |
| `undeadKills` | 그 영웅이 마지막 일격을 넣은 undead·spirit 몬스터 |
| `eliteKills` | 그 영웅이 마지막 일격을 넣은 정예 |
| `raidKills` | 레이드 단계 처치에 참여 |
| `downed` | 전투에서 쓰러졌다가 원정이 끝날 때 살아 있음(부활·불굴·승리 포함) |
| `healed` | 회복한 양의 합 |
| `abyssBest` | 심연에서 가 본 가장 깊은 층 |

5d 월간 마을 운영(시드 2)에서 초안은 마을 Lv10에 10명이 칭호를 보유했다. 조정 후 첫 획득은 16.3일, Lv10 도달 시점(25.0일)에 2명, 이후 30일 시점에 9명이었다. 성자와 치유의 손길을 같은 성직자 자리에 넣은 5d 비교(산적 요새 Lv14, 12개 파티 × 8전)에서는 대조군과 두 실험군 모두 96승이었다. 이 표본에서는 승률 차이를 구별하지 못했다. 성자의 회복 계수는 +5%, 천부는 +10%다.

## 저장

세이브 버전을 하나 올린다.

- `Hero.deeds?: Partial<Record<DeedKey, number>>`, `Hero.titles?: TitleId[]`(최대 3).
- 칭호를 얻은 순간을 알리기 위해 `GameState.titleLog: { heroId, title, at }[]`(최근 20).
- 예전 세이브: 행적 0, 칭호 없음. 단 `clears`·`raidKills` 등 이미 있는 기록으로 채울 수 있는 것은 채우지 않는다(처음부터 센다. 오래된 영웅이 갑자기 칭호를 얻지 않게).

## 화면

- 영웅 카드·상세·방문자 카드에 칭호 배지(천부 배지와 다른 색). 누르면 설명과 얻은 때. 상세에 행적 표(다음 칭호까지 진행).
- 칭호를 얻으면 원정 결과에 한 줄과 작은 연출, 재접속 보고에 한 줄, 알림.
- 명예의 전당·묘지의 영웅 기록에 칭호.
- 도감에 "칭호" 칸(마을에서 한 번이라도 나온 칭호, 10개).
