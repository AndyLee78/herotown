# 영웅 개성: 스킬과 장비 (2026-11-26)

지금은 같은 직업이면 영웅끼리 거의 같다. 스킬이 직업마다 넷뿐이고(둘을 고른다), 장비는 공격·방어 숫자와 옵션 하나(공격 또는 방어)뿐이다. 장비를 얻는 길도 제작뿐이다. 이 문서는 영웅마다 싸우는 방식이 달라지게 만든다.

## 결정 사항 (2026-11-26)

- 직업마다 스킬 **10개**: 기본기 하나와 **세 갈래 × 세 스킬**.
- 영웅마다 타고나는 **고유 스킬(천부)**. 자손에게 **유전**된다.
- 장비: **직업별 무기 종류**, **무작위 옵션 여러 개**, **보스·레이드 고유 장비**, **세트 장비** 모두.
- 성격·사기·파티 구성에 따라 효과가 달라지는 **조건부 효과**를 넣는다.

## 단계

| 단계 | 내용 |
| --- | --- |
| 5a | 스킬 갈래(직업마다 10개), 갈래 숙련, 조건부 효과, 천부와 유전, **몬스터 특성과 세기 조정** |
| 5b | 무기 종류, 무작위 옵션(1–3개), 옵션 다시 굴리기 |
| 5c | 던전 장비 드롭, 보스·레이드 고유 장비, 세트, 전리품·훈장 교환 |
| 5d | 밸런스 측정(직업·갈래별 승률, 장비 기대 성능) |

각 단계는 지금처럼 core·데이터·테스트(Claude Code) → 3D(Cursor)와 화면(GPT) → 리뷰·측정(GPT) 순서다.

## 5a. 스킬 갈래

### 규칙

- 첫 스킬(기본기)은 타고난다. 나머지 아홉은 **세 갈래**에 셋씩 나뉜다.
- 스킬을 고르는 레벨: **3, 7, 11, 15, 20, 25** (여섯 번). 아홉 중 여섯을 배운다. 그래서 같은 직업이라도 한 갈래를 버리거나, 셋 모두 조금씩 고르는 등 구성이 갈린다.
- 갈래 안에서는 순서가 있다. 갈래의 2번째 스킬은 1번째를, 3번째는 2번째를 배워야 배울 수 있다.
- **갈래 숙련:** 한 갈래의 세 스킬을 모두 배우면 그 갈래의 숙련 효과가 붙는다. 여섯 번 고르므로 숙련은 최대 둘이다.
- 기존 스킬은 그대로 각 갈래의 첫 스킬로 들어간다. 기존 세이브의 영웅은 배운 스킬을 지키고, 레벨에 맞춰 포인트를 다시 받는다.
- 훈련소의 "다시 고르기"는 갈래 끝에서부터 하나씩 잊는다(갈래 중간을 뽑을 수 없다).

### 새 효과 종류

지금 있는 효과(attack, guard, speed, heal, threat, bleed, weaken, regen, partyGuard, partyAttack, volleyEvery, cleanse)에 더한다.

| 키 | 효과 |
| --- | --- |
| `crit` | 치명타 확률(치명타는 ×1.5) |
| `critDamage` | 치명타 배율 추가 |
| `pierce` | 적 방어 무시 비율 |
| `lifesteal` | 준 피해의 일부만큼 회복 |
| `execute` | 체력 30% 아래 적에게 피해 + |
| `bossDamage` | 보스에게 피해 + |
| `counter` | 맞을 때 확률로 반격(×0.6) |
| `dodge` | 공격을 피할 확률 |
| `stun` | 공격한 적이 확률로 한 번 쉰다 |
| `slow` | 공격한 적의 속도 − (층 동안) |
| `burn` | 화염 지속 피해(출혈과 따로 쌓인다) |
| `shield` | 층 시작에 파티 전원에게 최대 체력 %만큼 보호막 |
| `firstStrike` | 층 첫 행동의 피해 + |
| `lastStand` | 체력 30% 아래에서 공격·방어 + |
| `revive` | 층마다 한 번, 쓰러진 동료를 체력 일부로 일으킨다 |
| `partySpeed` | 파티 전원 속도 + (상한 있음) |
| `enemyMiss` | 적 공격이 빗나갈 확률(파티 전체, 상한 있음) |
| `holy` | 언데드(망령·유령·리치 등)에게 피해 + |

몬스터에 `undead` 표시가 필요하다(`monsters.json`).

### 조건부 효과

스킬 효과에 `when` 조건을 달 수 있다. 조건이 맞으면 `bonus` 효과가 더해진다.

| 조건 | 뜻 | 예 |
| --- | --- | --- |
| `personality` | 그 성격일 때 | 다혈질 + 분노: 공격 +4% 더 |
| `moraleAbove` / `moraleBelow` | 출발할 때 마을 사기 | 영웅담: 사기 70 이상 |
| `hpBelow` | 전투 중 자기 체력 비율 | 결사: 30% 아래 |
| `withClass` | 파티에 그 직업이 있으면 | 성직자와 함께면 전사 결사 +5% |
| `bonded` | 파티에 호감도 높은 동료(친구 이상)가 있으면 | 사교적 + 찬가: 파티 공격 +1% 더 |

**성격과 갈래의 궁합.** 성격마다 잘 맞는 갈래 종류가 있다. 맞는 갈래의 스킬은 효과가 +20%다.

| 성격 | 잘 맞는 갈래 |
| --- | --- |
| 다혈질 | 광전, 암살, 화염, 칼날 |
| 소심 | 수호, 그림자, 평온, 매혹 |
| 야심 | 저격, 심판, 용기, 도발 |
| 온화 | 치유, 수호(성직자), 평온 |
| 사교적 | 용기, 바람, 비전 |
| 외톨이 | 그림자, 사냥, 서리 |

화면은 스킬을 고를 때 궁합이 맞는 갈래에 표시를 단다.

### 천부 (고유 스킬)

영웅마다 **0개 또는 1개**. 이름 옆에 금빛 표시로 보인다.

| 천부 | 효과 |
| --- | --- |
| 불굴 | 층마다 한 번, 쓰러질 피해를 체력 1로 버틴다 |
| 선봉 | 층 첫 행동을 두 번 한다 |
| 쌍격 | 공격이 10% 확률로 한 번 더 맞는다 |
| 천리안 | 파티가 함정·기습을 받지 않는다 |
| 강철 체질 | 원정 피로 −25% |
| 치유의 손 | 받는 회복 +15%, 주는 회복 +10% |
| 용의 피 | 화염·독 피해 −40% |
| 명사수 | 치명 +8%, 치명 배율 +0.2 |
| 행운아 | 원정 골드·재료 +10%, 장비 드롭 +(5c) |
| 전술가 | 파티 속도 +3% |
| 늦깎이 | Lv15 이후 경험치 +30% |
| 영웅의 핏줄 | 모든 능력치 잠재력 +2 |
| 수호천사 | 파티가 전멸하면 한 번, 모두 체력 20%로 일어난다(원정마다) |
| 노래꾼 | 파티 공격 +2% |

- **처음 나올 확률:** 방문자 6%, 대등대 단계마다 +1%.
- **유전:** 아이가 태어날 때 부모 중 천부가 있는 쪽마다 40%로 물려받는다(둘 다면 하나를 고른다). 물려받지 못하면 6%로 새로 굴린다.
- 유품 계승과 따로 간다. 명예의 전당에 오른 영웅의 천부는 가문 기록에 남는다.

### 몬스터 (5a)

영웅이 스킬 여섯 개·숙련·천부를 갖게 되면, 몬스터를 그대로 두면 너무 쉬워진다. 숫자만 올리면 고른 스킬이 의미가 없다. 그래서 **몬스터마다 강점과 약점을 달아서, 갈래 선택이 던전마다 다르게 먹히게** 한다.

**종류 표시.** `kind`: `beast`(짐승), `undead`(언데드), `human`(사람), `construct`(골렘류), `dragon`(용족), `spirit`(정령). 지금의 `weakHoly`는 `undead`·`spirit`로 바꾼다. 퇴마·심판 갈래와 보스·세트 효과가 이 표시를 본다.

**새 몬스터 특성.**

| 특성 | 효과 | 막히는 것 / 뚫는 것 | 주로 붙는 몬스터 |
| --- | --- | --- | --- |
| `armor` | 방어가 높고, 일반 공격 피해 −20% | 관통·치명이 뚫는다 | 골렘, 무덤 기사, 드레이크 |
| `evasive` | 공격을 15% 피한다 | 광역(일제 사격·강타·회오리)은 피하지 못한다 | 박쥐, 망령, 와이번, 자객 |
| `nodot` | 출혈·맹독 같은 지속 피해가 안 듣는다 | 화상, 직접 피해 | 해골, 뼈 궁수, 이끼 골렘 |
| `fireproof` | 화상이 안 듣고 화염 무기 피해 −30% | 서리·비전 갈래 | 드레이크, 와이번, 고룡 |
| `healer` | 자기 차례에 가장 다친 동료를 회복 | 처형·기습·집중 공격으로 먼저 잡기 | 코볼트 주술사, 늪 위스프, 강령술사(새) |
| `thorns` | 맞을 때 피해의 10%를 돌려준다 | 치명 위주보다 지속 피해, 흡혈로 버티기 | 이끼 골렘, 독두꺼비 |
| `enrage` | 정해진 행동 수가 지나면 공격 +50% | 오래 끄는 탱커 파티를 벌한다. 딜 갈래가 필요 | 3티어 이상 모든 보스 |
| `steadfast` | 기절·감속 확률 약 ⅓ | 보스에게 제어가 너무 세지 않게 | 모든 보스 |
| `cleanse` | 몇 차례마다 자기 약화·감속을 지운다 | 약화를 자주 다시 거는 불협·독 갈래 | 늪의 여왕, 성채 군주 |

- 한 몬스터에 특성은 하나 또는 둘. 던전마다 섞어서 **한 가지 갈래만으로는 모든 던전을 쉽게 못 깨게** 한다. 예를 들면 이렇다.
  - 지하묘지: 출혈·독이 안 듣는다. 심판·화염·관통이 좋다.
  - 독늪: 회복하는 위스프, 가시 골렘이 있다. 처형·광역·정화가 좋다.
  - 도적 요새: 회피하는 자객이 있다. 광역·사냥(기습 면역)이 좋다.
  - 용의 둥지: 화염이 안 듣고 단단하다. 서리·관통·보스 피해가 좋다.
- **정예 몬스터:** 4티어 이상에서 일반 몬스터가 10% 확률로 정예가 된다. 정예는 체력 ×1.6에 무작위 특성 하나가 더 붙는다. 이름 앞에 "정예" 표시가 붙는다. 5c에서 정예는 장비를 조금 더 잘 떨어뜨린다.
- **새 몬스터:** 가라앉은 지하묘지 2층의 망령 자리에 강령술사(언데드, healer)를 넣는다. 다른 던전은 지금 몬스터에 특성만 단다.

**세기 조정.**

- 기준은 기존 balance와 같다. **권장 레벨에서, 그 레벨에 맞는 스킬 수를 배운 파티가 하위 25% 승률 약 80%**다.
  - 스킬 수는 Lv3 1개, Lv7 2개, Lv11 3개, Lv15 4개, Lv20 5개, Lv25 6개다.
  - 숙련은 Lv15 이후 하나, Lv25에 둘까지로 본다.
- 1–2티어(권장 Lv1–8)는 스킬이 두 개까지라 숫자를 그대로 둔다. 특성만 단다.
- 3티어 이상은 특성을 단 뒤 측정해서 체력·공격을 맞춘다. 첫 추정은 3–4티어 ×1.1, 5티어 ×1.2, 6–7티어 ×1.3이다.
- 시련·심연·레이드·침공·이벤트는 각자 `scale`이 있으므로, 측정 뒤 그 값만 다시 맞춘다.
- 측정은 `tools/curve.ts`와 `tools/endgame-4a.ts`에 갈래 조합(직업마다 "한 갈래 몰기"와 "고르게")을 더해 GPT가 한다(5a 측정 작업).
- **목표:** 직업마다 가장 센 조합과 가장 약한 조합의 차이가 레벨 +2를 넘지 않는다. 던전마다 1등 조합이 같지 않다.

### 구현 메모 (core, 2026-11-26)

- 스킬을 고르는 레벨은 3, 7, 11, 15, 20, 25다. 기존 스킬은 각 갈래의 첫 스킬이고, 이름·효과·종류가 그대로다. 그래서 Lv7 이하의 기존 밸런스는 성격 궁합(+20%) 말고는 바뀌지 않는다.
- "감속"과 "기절"은 확률이다. 덫·서리·자장가는 공격한 적을 그 확률로 감속시키고(3차례, 게이지 ×0.7), 마비독·빙결은 그 확률로 한 차례 쉬게 한다. 보스는 그 확률이 ×0.34다.
- 조건(`when`)은 출발할 때 정해진다. 사기는 그 영웅의 사기, "친한 동료"는 파티의 유대 보너스가 있는지로 본다. 체력 조건은 결사(`lastStand`) 하나뿐이고 전투 중에 매번 본다.
- 파티 효과의 상한: 받는 피해 −8%, 공격 +6%, 속도 +6%, 치명 +6%, 적 빗나감 +8%, 보호막 10%, 언데드 피해 +10%, 첫 행동 +15%, 피로 −20%. 회피는 40%까지다.
- 정예: 4티어 이상 던전(특수 던전 포함)의 일반 몬스터가 10%로 정예가 된다. 리플레이 유닛에 `elite: true`.
- 분노: 3티어 이상 보스는 24번째 행동부터 공격 ×1.5다. 레이드 보스도 같다(5a 측정에서 레이드에 미치는 영향을 본다).
- 강령술사는 처음 숫자(체력 70, 공격 13)로는 지하묘지 권장 레벨 승률이 42%로 떨어져서 체력 60, 공격 10으로 낮췄다.
- 행운아는 원정 골드 +10%(장비 드롭은 5c), 강철 체질은 자기 피로 −25%, 위로는 파티 피로 −10%다.
- 새 전투 로그: `log.miss`, `log.crit`, `log.burn`, `log.thorns`, `log.counter`, `log.twin`, `log.enrage`, `log.purge`, `log.revive`, `log.undying`, `log.guardian`. 보호막이 막은 양은 `params.absorbed`.

### core (5a)

- `classes.json`: 스킬마다 `branch`(0–2, 기본기는 없음), `tier`(1–3). 직업마다 `branches: [{ id, mastery: SkillEffect }]`.
- `training.json`: `pickLevels` [3, 7, 11, 15, 20, 25].
- `skills.ts`: `canLearn`(갈래 순서), `masteries(hero)`, `heroSkillEffects`에 숙련·궁합·조건부 반영. 전투 중 조건(`hpBelow`)은 combat이 매 행동 확인.
- `types.ts`: `Hero.gift?: GiftId`. `traits.json` 옆에 `gifts.json`.
- `combat.ts`: 새 효과 키 처리. 몬스터 `kind`, 특성 10종, 정예.
- `monsters.json`: `kind`, `traits`. 강령술사 추가. `weakHoly`는 읽을 때 `kind`로 바꾼다.
- 세이브 27: `gift` 없음 → 그대로(새로 굴리지 않음). 배운 스킬은 갈래 순서를 지키는 것만 남긴다.
- 화면용: `canLearn`, `canForget`, `skillPrerequisite`, `masteries`, `suitedBranches`, `giftEffect`, `heroSkillEffects(hero, { allies, bonded })`.

## 5b. 무기 종류와 무작위 옵션

### 무기 종류

| 무기 | 성격 | 쓰는 직업 |
| --- | --- | --- |
| 검 | 균형 | 전사, 도적, 무희 |
| 도끼 | 공격 +15%, 속도 −5% | 전사 |
| 방패검 | 공격 −15%, 방어 +큰 폭 | 전사 |
| 단검 | 공격 −10%, 치명 +8% | 도적, 무희 |
| 활 | 균형 | 궁수 |
| 석궁 | 공격 +15%, 속도 −8%, 방어 무시 10% | 궁수 |
| 지팡이 | 균형 | 마법사, 성직자 |
| 마도서 | 공격 −10%, 속도 +6% | 마법사 |
| 홀 | 회복 +10% | 성직자 |
| 류트 | 파티 효과 +10% | 음유시인 |
| 부채 | 회피 +5% | 무희 |

- 레시피는 등급 × 무기 종류로 나뉜다(철검·철도끼…). 쓸 수 없는 직업은 장착할 수 없다.
- 기존 무기는 "검"으로 읽되, 검을 못 쓰는 직업이 끼고 있으면 그 직업의 기본 무기로 바꾼다.

### 무작위 옵션

- 고급 1개, 희귀 2개, 영웅·전설 3개. 옵션마다 값이 범위 안에서 굴려진다.
- 옵션 풀: 공격 +, 방어 +, 체력 +%, 치명, 속도, 회복, 화염 저항, 독 저항, 보스 피해, 언데드 피해, 경험치, 골드.
- 기존 `option`(power/guard)은 같은 값의 옵션 하나로 바꾼다.
- **다시 굴리기:** 옵션 하나를 골라 용맹 훈장으로 다시 굴린다(지금 `setOption` 대신). 고정은 없다.

## 5c. 드롭·고유 장비·세트

- **던전 드롭:** 보스를 쓰러뜨리면 작은 확률로 그 던전 등급의 장비(옵션 포함)가 떨어진다. 첫 클리어는 확정 하나.
- **보스 고유 장비:** 티어 보스마다 하나, 레이드 보스마다 둘. 이름과 고유 효과가 있다(예: 묘실 군주의 왕관 — 언데드 피해 +20%, 층마다 한 번 부활). 레이드 2·3단계에서 확률이 오른다.
- **교환:** 쌓인 전리품(용비늘·왕관·핵)과 용맹 훈장으로 고유 장비를 바꿀 수 있다(드롭보다 비싸게).
- **세트:** 무기·방어구·장신구에 걸친 세트 4종. 2개·3개 보너스. 예: 용사냥꾼(화염 저항 / 보스 피해 +15%), 묘지기(언데드 / 부활), 바람걸음(속도 / 회피), 성가대(회복 / 파티 보호막).

5b·5c의 세부 숫자는 5a를 마친 뒤 확정한다.

## 5d. 측정

- 직업마다 갈래 조합(숙련 0·1·2)별 승률. 한 조합이 다른 조합보다 레벨 +2 이상 강하면 줄인다.
- 천부별 효과 크기(천부 없는 같은 영웅과 비교).
- 장비 기대 성능: 같은 등급에서 옵션 최상·최하의 차이.
